# Anghan Mehul — Resume & Portfolio

Premium personal site for **Anghan Mehul**, Full Stack Developer (Shopify & WordPress).

## Pages

| Path | Description |
|------|-------------|
| `/resume/` | Professional resume / career profile |
| `/portfolio/` | Selected work with category filters |

Root (`/`) and legacy `portfolio.html` redirect to the pages above.

## Stack

- HTML5, modern CSS3, vanilla JavaScript
- No Bootstrap / jQuery / build step
- Dark / light theme (persisted in `localStorage`)
- Color system: teal brand (`#0F766E` / `#14B8A6`), slate text (`#0B1220`), dark cards (`#111827`)

## Local preview

```bash
npx serve .
```

Then visit `/resume/` and `/portfolio/`.

## Assets

- Icons/SVGs: `assets/images/`
- Portfolio & profile photos: `assets/images/optimized/` (WebP + JPEG)
